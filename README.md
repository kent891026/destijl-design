# De Stijl Studio

> 將風格派的格線、原色與比例，轉譯為可探索、可重現、可輸出的生成式設計工具。

## 操作方式

畫布使用固定 **50 × 50 boundary**：格子永遠維持正方形。25 × 25 會在 boundary 中完整填滿並將每格放大兩倍；50 × 40 會填滿寬度並留下 10 個高度單位的邊界空區，不會壓縮圖形。調整色彩／階數比例、拖曳色塊重新排版，或輸入文字／上傳圖片來建立色彩矩陣；每張作品都附有 Seed，可匯出 PNG。

## 設計與技術亮點

- **比例守恆**：調整一種色彩時，系統自動平衡其他比例，總和固定為 100%。
- **可重現的偶然**：以 seeded pseudo-random generator 保存探索過程中的作品版本。
- **動態規劃構圖**：以每列累積的連續空白高度，找出得分最高的可用矩形來填補畫布；保有視覺節奏，也能快速完成局部重排。
- **色彩隨機漫步**：以「配額約束圖著色＋模擬退火」反覆換色；共享邊越長的同色相鄰代價越高，同時維持各色面積比例。
- **階數配額**：可設定 1 到 n 階矩陣的面積比例；n 階區塊的長、寬皆不超過 n，且至少一邊為 n。
- **即時局部重排**：拖放色塊後優先將被擠出的原區塊安置回來源位置及移動路徑附近，只有無法安置者才移除，再以動態規劃補洞。
- **文字／影像矩陣**：文字以字元編碼、圖片以目前畫布尺寸的 RGB 取樣轉為矩陣；高對比區保留小格，平坦色面生成較大色塊。
- **Apple 風格工作區**：滿版畫布搭配玻璃感浮動控制器；按鈕具備 hover、pressed 與焦點回饋。

## 本機執行

```bash
npm ci
npm run dev
```

在瀏覽器開啟 `http://localhost:3000`。

src/components/
