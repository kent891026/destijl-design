# De Stijl Studio

> 將風格派的格線、原色與比例，轉譯為可探索、可重現、可輸出的生成式設計工具。

## 操作方式

畫布採固定格點而非等比例縮圖：20×30 會佔用 20 欄、30 列的實際工作區，調整為 21×30 時會直接增加一欄。調整色彩比例、拖曳色塊重新排版，或輸入文字／上傳圖片來建立色彩矩陣；每張作品都附有 Seed，可匯出 PNG。

## 設計與技術亮點

- **比例守恆**：調整一種色彩時，系統自動平衡其他比例，總和固定為 100%。
- **可重現的偶然**：以 seeded pseudo-random generator 保存探索過程中的作品版本。
- **構圖演算法**：先配置主要矩形、再以方向性長條填滿，分色時兼顧配額與相鄰色彩排斥。
- **即時局部重排**：拖放色塊後優先保留拖曳目標、移除碰撞矩形，再重建尚未填滿的格子。
- **文字／影像矩陣**：文字以字元編碼、圖片以 20×20 RGB 取樣轉為色彩矩陣，成為構圖的資料來源。
- **Apple 風格工作區**：滿版畫布搭配玻璃感浮動控制器；按鈕具備 hover、pressed 與焦點回饋。

## 本機執行

```bash
npm ci
npm run dev
```

在瀏覽器開啟 `http://localhost:3000`。
